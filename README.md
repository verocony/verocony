## 🏢 하는 일

> **어떤 서비스인가요?** — 스프레드시트처럼 익숙한 Grid 위에서 Chart · Form · Calendar · Timeline 화면을 만들고,
> 데이터 변경·시간 조건에 따라 동작하는 업무 자동화까지 코딩 없이 구성하는 B2B 노코드 서비스

### 🤖 AI 자동화 빌더
- 채팅으로 "이런 자동화 만들어줘"라고 말하면 자동화 흐름을 생성하는 화면
- React Flow 캔버스로 트리거·조건·액션 흐름 시각화
- 액션 편집 패널 ↔ 생성된 스크립트 **양방향 동기화**, 변경 전후 **diff 뷰어**, 실시간 lint

### ⚙️ 자동화 편집기 · 디버거
- Monaco 기반 자동화 스크립트 편집기
- 중단점 · 조건부 중단점 · 단계 실행을 지원하는 디버거 UI
- 시간 트리거 · 수신자 지정 등 자동화 설정 화면

### 📊 Grid
- 캔버스 렌더링 그리드의 컬럼 메뉴 · 데이터 필터 · 참조(Lookup) 설정 · 수식 편집기
- 다른 Grid의 데이터를 가져와 보는 원본 데이터 조회 화면

### 🗂 Page · View 컴포넌트
- WorkSpace의 페이지 목록 · 트리 탐색, 컴포넌트 생성 흐름
- Calendar · Timeline · Form 뷰
- 한국어 · 영어 다국어(i18next), Figma 시안의 픽셀 단위 구현

### ✅ 품질 · 개발 방식
- Vitest 단위 테스트, Cypress E2E와 테스트 데이터 seed 체계
- Claude Code 서브에이전트 · 스킬을 구성해 코드 리뷰 · 브라우저 실측 · 테스트 검증을 자동화
